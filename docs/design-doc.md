## 🔮 一、 痛点分析与黑客松赛题契合

### 1. 现实痛点：多人出行“众口难调”
在日常生活中，周末与伴侣、朋友同行时，常遇到**“去哪儿玩”**的决策矛盾。不同个体的状态、喜好和心境千差万别，传统的搜索推荐算法往往只能提供单调的折中方案，缺乏情感共鸣和个性化张力。

### 2. 创意火花：“你信塔罗，我信算命”
本项目别具匠心地引入了**东西方双玄学神秘学系统（东方生辰八字 + 西方经典塔罗）**作为出行驱动力。
- 用户A 可以使用 **西方塔罗牌** 倾诉其“电量告急/灵感枯竭”等当前实时情绪。
- 用户B 可以使用 **东方生辰八字** 注入生年月日时等时空命理信息。

我们的 **AI Agent 核心规划御史** 将两人的运势磁场进行命运羁绊的逻辑相生计算，筛选出与他们五行互补、精神契合的真实高德 POI 商户，编织成一条 2-6 小时动静结合的完美周末探索轨迹。这不仅是一份出行指南，更是一场充满神秘感与仪式感的“命运会盟”。

### 2. 精准八字算法 (`baziHelper.ts`)
我们在后端实现了无第三方依赖的高精度干支历法转换算法：
- **年柱**：以公历纪年进行岁差基准换算，并精确考虑立春气节前后的岁首跨越。
- **月柱**：通过“五虎遁”口诀（如“甲己之年丙作首”）根据年干自动推导月干支。
- **日柱**：采用高精度儒略日偏移法，以 2000年1月1日（戊午日）为天文锚点进行天数差模60循环运算，计算出精确日天干（日主）与日地支。
- **时柱**：通过“五鼠遁”口诀（如“甲己还加甲”）依据日干与时间区间计算时干支。
- **五行比重**：统计八字在【金、木、水、火、土】中的能量比重，找出缺憾五行作为“幸运五行”直接输入给 AI 规划 Prompt。

### 3. Tool Calling 编排与 Mock 预订链
为了让活动方案“真实可落地”，AI 在返回方案时会自动注入工具链调用协议。
- 后端提供 `/api/agent/book` 模拟履行接口。
- 支持三类核心工具：
  - `didi_call` (滴滴像素专车)：一键呼叫，前端模拟司机接单距离递减动画。
  - `spot_ticket` (美团闪购/门票预订)：同步锁库存并发送兑换码。
  - `meituan_coupon` (限时卡券注入)：直接写入美团卡包。
- 保证了 AI Agent 在没有真实高频商业密钥的情况下，依然呈现 100% 完整的系统闭环。

## 🗺️ 三、 高德地图多站点串联与像素渲染

高德地图 JS API v2.0 在产品中得到了深度定制与重构：
1. **多段路径串联 (Leg-based routing)**：前端获取 Agent 锁定的顺序商户后，调用 `AMap.Walking` 进行分段步行导航，首创在地图上将 Leg 1、Leg 2、Leg 3 以不同色系高对比度线条（金色、蓝色、红色）组合呈现，路线质感强烈。
2. **像素化视觉覆层**：折线开启 Outline 及高宽度黑边，将粗线条像素化处理。
3. **结界漫步**：在地图路线各节点渲染组队成员的像素小人头像，小人随连线位置行进，契合 RPG 冒险画风。

## 🎨 四、 极致复古像素美学设计

本项目在视觉体验上追求 Wow-factor，避免了平庸的 MVP 质感：
- **黄金八字乾坤盘**：采用金色像素框，结合“日主”特殊高亮角标，并伴有五行渐变指示条，直观且高贵。
- **3D 塔罗牌翻页**：利用 CSS 3D `perspective` 结合 Framer Motion 驱动的 Y 轴旋转翻牌，实现极富仪式感的抽牌悬念。
- **命运契约羊皮纸**：使用细边框多重阴影，制造复古卷轴垂落的呼吸特效。
